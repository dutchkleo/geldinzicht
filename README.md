# geldinzicht
Een lokaal dashboard voor financiele overzicht: importeer je csv

Hoi Claude.ai, wil je een dashboard voor me maken voor csv-geldzicht? 

Uw dashboard is klaar! Sla het HTML-bestand op uw computer op en open het gewoon in uw browser — geen internetverbinding of installatie nodig.
Wat er allemaal in zit:

📥 Importeren
Sleep meerdere CSV-bestanden tegelijk in (van alle 4 rekeningen + spaarrekeningen + de andere bank)
Per rekeningnummer kunt u instellen: naam, eigenaar (Ik / Man / Zoon / Huisrekening / Andere bank) en type (betaal- of spaarrekening)
Dubbele transacties worden automatisch herkend en niet dubbel geladen

📊 Dashboard
KPI-blokken: inkomsten, uitgaven, spaartransfers, netto resultaat, aantal transacties
Filter op maand, jaar en rekening
Staafgrafiek inkomsten vs. uitgaven per maand
Donut-grafiek uitgaven per categorie
Voortgangsbalken top-categorieën
Recente transacties

≡ Transacties
Alle kolommen uit uw CSV zichtbaar (incl. Saldo na mutatie, Tag, Tegenrekening)
Zoeken, filteren op maand/jaar/rekening/categorie/richting
Sorteren op datum, naam of bedrag
Per transactie categorie toewijzen — met optie "ook toepassen op alle gelijkaardige"

◉ Categorieën
Standaard categorieën (Inkomen, Wonen, Boodschappen, Transport, Sparen, Zorg, Vrije tijd)
Eigen categorieën toevoegen met kleur en zoektermen
Automatisch labelen op basis van naam/omschrijving

∿ Trends
Jaarlijks overzicht over 7 jaar
Gemiddeld inkomen/uitgave per maand per jaar
Trend per top-5 categorie

Instellingen: scheidingsteken, decimaalteken en datumformaat instelbaar (standaard op Nederlandse ING/Rabobank-stijl). Alle data wordt lokaal in uw browser opgeslagen.
